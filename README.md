🎁 Daisy Donation Backend
This is the backend component of the Daisy Donation System, a Spring Boot application that handles donation processing, receipt generation, and multi-channel delivery (email, SMS, and WhatsApp).

🚀 Features
RESTful API for donation handling

Integration with payment gateways (e.g., Stripe, control numbers)

Auto-generation of PDF donation receipts

Sending receipts via email, WhatsApp, and SMS

Secure API endpoints with authentication

Donor and donation record management

Scheduled jobs for follow-ups and confirmation messages

🛠️ Built With
Java 17+

Spring Boot

Spring Data JPA

Spring Scheduler

PostgreSQL

Twilio API – SMS & WhatsApp

JavaMailSender – Email

iText or OpenPDF – PDF generation
